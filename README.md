
# CSS Box Model — Навчальні картки

## Мета проєкту
Створення двох навчальних карток для демонстрації
роботи CSS Box Model, відступів та позиціювання.

## Використані властивості

- box-sizing: border-box — глобальний розрахунок розмірів.
- padding — внутрішні відступи.
- border — рамки карток.
- margin — зовнішні відступи.
- position: relative — позиціювання картки.
- position: absolute — позиціювання позначки.
- overflow-wrap — контроль довгого тексту.

## Перевірка

Розміри двох карток і позиціювання позначки
перевірено в DevTools.

На вузькій ширині позначка не перекриває заголовок,
а горизонтальний скрол сторінки відсутній.
